# WillThisFit design system (v1, October 2026)

The tokens live as CSS custom properties at the top of the app's style block (`src/WillThisFit.jsx`, search for "DESIGN TOKENS"). Every light value has a dark-mode pair under `.dark-app`. **Use tokens, not hex values, in new code.**

## Colour
| Token | Light | Dark | Use |
|---|---|---|---|
| `--c-bg` | #f5f3ee | #0d1a14 | Page background ("Paper") |
| `--c-surface` / `--c-surface-2` | #ffffff / #f7f5f0 | #14231a / #1a2d21 | Cards / tiles, inputs |
| `--c-border` / `--c-border-strong` | #e6e1d7 / #d6d0c4 | #2a4535 / #365a45 | Dividers, outlines |
| `--c-ink` / `--c-ink-2` / `--c-ink-3` | #122318 / #4f5b52 / #7c857e | #e6f1ea / #a9c2b2 / #7f9a89 | Text: primary / secondary / quiet |
| `--c-brand` | #2d7a4a ("Forest") | same | Solid buttons, selected pills |
| `--c-brand-text` / `--c-brand-tint` | #1e6a3c / #eaf4ee | #7fd9a3 / #173525 | Links, positive badges |
| `--c-mint` | #4db87a | same | Accent on dark: the ".me", the mark |
| `--c-night` | #0e1e14 | same | Header, footer, app icon |
| `--c-danger`, `--c-warn`, `--c-info`, `--c-violet` (+ `-tint`, `-border`) | | | Audit flags, warnings, info |

## Type
- **Fraunces** (`--f-display`): headings, the wordmark, numbers in size tiles.
- **Instrument Sans** (`--f-ui`, class `.ins`): interface, body text, labels.

## Shape
- Radius: `--r-sm` 8 (inputs, chips), `--r-md` 12 (tiles), `--r-lg` 16 (cards), `--r-pill` (pills, badges).
- Elevation: `--sh-1` (cards), `--sh-2` (dialogs).
- Focus: every interactive element shows a 2px `--c-focus` outline on keyboard focus.

## Logo files (`public/brand/`)
These are generated by a script that renders the lettering as outlines, so they look identical without the fonts installed.
- **Mark:** `mark.svg`, `mark-on-dark.svg`
- **App icon:** `app-icon.svg`, plus PNGs `favicon-32`, `apple-touch-icon`, `icon-512`
- **Wordmark:** `wordmark.svg`, `wordmark-on-dark.svg`
- **Credit badge:** `powered-by.svg`, `powered-by-dark.svg`
- **Social share image:** `og-image.png` (1200 × 630)

In React, use `Mark` and `Wordmark` from `src/brand.jsx`, and `PoweredBy` from `src/Pages.jsx`.

## Embed
`public/embed.js` turns `<div data-willthisfit …>` into an auto-resizing iframe of `/embed`. `/embed` is the app without its header, hero, navigation or footer, and with sign-in controls hidden (`.no-embed`). It always shows the "Size data by WillThisFit" credit.
